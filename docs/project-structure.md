# Структура проекта

[← К README](../README.md)

| Путь | Назначение |
|---|---|
| `index.html` | страница и стили (точка входа) |
| `sw.js` | service worker: «сначала сеть, при неудаче — кеш», приложение открывается без интернета |
| `manifest.webmanifest`, `icons/` | манифест и иконки: приложение можно добавить на главный экран |
| `src/app.js` | интерфейс: загрузка карт и графа, выбор аудиторий, поиск, отрисовка маршрута, шаги |
| `src/gestures.js` | жесты на карте (Pointer Events: перемещение, щипок, двойное нажатие, колесо) |
| `src/viewmath.js` | математика вида карты (масштаб, поворот, сдвиг), без DOM |
| `src/graph.js` | валидация графа, индекс, поиск кратчайшего пути (Дейкстра) |
| `src/heap.js` | бинарная куча для Дейкстры |
| `src/culling.js` | отсечение элементов за экраном: видимый прямоугольник и пересечения, без DOM |
| `src/share.js` | ссылка на маршрут (`?from=…&to=…`): сборка и разбор |
| `src/vendor/qrcode.js` | генератор QR-кода [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT, подключён как есть) |
| `src/compass.js` | компас: направление по углам датчика, сглаживание по кругу, поворот карты, калибровка; без DOM |
| `src/nav.js` | экраны и навигация: экран из адреса (`#/search`, `#/share`), поведение «Назад», без DOM |
| `src/signs.js` | поиск номера на фото: тёмные цифры на светлом → рамки с рядами цифр → выбор номера, который есть в здании; без DOM |
| `src/steps.js` | пошаговый показ маршрута: что видно (текущий и следующий шаг), когда есть стрелки, как распознать свайп, какой шаг показать при выборе этажа; без DOM |
| `src/names.js` | поиск места по тексту надписи («Серверная», «Кафедра математического анализа…»): слова по первым 6 буквам, редкие слова весят больше, цифры в названии обязаны совпасть; без DOM |
| `src/ocr.js` | распознавание: фото → канвас → рамки → tesseract.js в веб-воркере; грузится только при первом снимке |
| `src/vendor/tesseract/` | tesseract.js 5.1.1 + ядро (WebAssembly) + модели `eng` и `rus` (около 10 МБ), лицензии и `NOTICE.md`; своих изменений нет |
| `src/session.js` | сохранение и проверка состояния (этаж, вид карты, маршрут, запрос) в `sessionStorage`, без DOM |
| `src/search.js` | поиск мест, избранное, недавние маршруты, работа с `localStorage` |
| `data/data.json` | граф здания (**генерируется**, вручную не править) |
| `maps/map1.svg`, `map2.svg`, `map3.svg` | планы этажей |
| `run.py` | запуск одной командой: окружение, граф, тесты, сервер |
| `tools/build_graph.py` | генератор `data/data.json` из SVG |
| `tools/bench.mjs` | замер поиска пути на синтетических зданиях (`node tools/bench.mjs`) |
| `bench/render.html` | замер отрисовки: 300/1000 аудиторий, с отсечением и без (открыть через `tools/serve.py`) |
| `tools/serve.py` | локальный сервер без кеширования (удобно для проверки на телефоне) |
| `tools/names.json` | русские названия особых зон и аудиторий |
| `test/` | тесты (`graph`, `viewmath`, `search`) |
| `debug/` | SVG с нарисованным графом для проверки глазами (создаётся скриптом) |
