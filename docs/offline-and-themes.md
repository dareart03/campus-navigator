# Работа без сети и темы

[← К README](../README.md)

- Первый запуск нужен с сетью: service worker кеширует файлы при первом открытии (работает по https и на `localhost`; по `http://<IP>` в локальной сети регистрироваться не будет — это ограничение браузеров).
- Онлайн всегда берутся свежие файлы, из кеша — только если сети нет.
- Полоса «Нет сети» ориентируется не только на `navigator.onLine` (на телефоне он часто остаётся `true` при Wi-Fi без интернета или выключенных данных), а проверяет связь запросом HEAD к `sw.js` раз в 15 секунд, при возврате на вкладку и при событиях сети. Service worker обрабатывает только GET, поэтому кеш не подменяет результат проверки.
- Страница `index.html` хранится в кеше под одним ключом, как бы её ни открыли («/», «/index.html», «/?from=…&to=…»). Раньше копии хранились под каждым адресом: онлайн обновлялась только та, с которой открыли, а офлайн по ярлыку отдавалась старая страница вместе с новым `app.js`, и приложение падало с ошибкой `Cannot read properties of null (reading 'addEventListener')`. Ошибка воспроизведена в браузере и исправлена; при выпуске новой версии меняется номер в имени кеша (`CACHE` в `sw.js`).
- Тема следует за системной (`prefers-color-scheme`). Проверить на компьютере: DevTools → ⋮ → More tools → Rendering → «Emulate CSS media feature prefers-color-scheme».
- Размер шрифта 1,3×: на Android — Настройки → Дисплей → Размер шрифта; на компьютере — Chrome → Настройки → Внешний вид → Размер шрифта.
