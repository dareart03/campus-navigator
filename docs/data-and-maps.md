# Данные и карты

[← К README](../README.md)

## Модель данных

`data.json` — один граф на всё здание:

- **узлы** `{id, x, y, floor, type, label}`; `type`: `room`, `door`, `corridor`, `stairs`, `wc`;
- **рёбра** `{from, to, weight, type}`; вес — длина в пикселях карты;
- id содержат этаж: `f3-room-311`, `f2-ladder-1`;
- лестницы одного номера на соседних этажах соединены рёбрами типа `stairs`. Вес такого ребра — «цена» одного этажа: два лестничных пролёта с площадкой (около 12–15 м пути, по лестнице идут медленнее), это порядка **200** единиц карты (`--stairs-weight` в `build_graph.py`, значение записывается в `meta.stairsWeight`). С прежними 40 лестница стоила как короткий кусок коридора, и «ближайший туалет» из аудитории на 2 и 3 этаже выбирался этажом ниже (на 2 этаже в 18 случаях из 68, на 3 этаже в 12 из 54); при 200 — ни разу. На 1 этаже левые аудитории по-прежнему ведут вверх: единственные туалеты 1 этажа стоят в правой части, и путь до них заметно длиннее, чем подняться к туалетам над левым крылом;
- аудитории — только начало или конец маршрута, сквозь них путь не идёт.

## Как обновить карту

Планы рисуются в векторном редакторе и экспортируются в SVG **с атрибутами `id`** (в Figma: настройки экспорта → *Include "id" attribute*). Нужные группы и имена слоёв:

- группы `corridor`, `Rooms`, `Ladders`, `Doors`, `Texts`;
- комнаты — `room-311`, двери — `door-311` (у комнаты несколько дверей — `door-325-1`, `door-325-2`), лестницы — `ladder-1…4`, двери лестниц — `door-ladder-1`.

Затем проще всего запустить `python run.py` (он выполнит и сборку, и проверки). Вручную:

```powershell
pip install -r tools/requirements.txt
python tools/build_graph.py                              # maps/*.svg -> data/data.json
python tools/build_graph.py --debug-dir debug            # + картинки графа для проверки
python tools/build_graph.py --check f3-room-311 f1-room-103   # + пример маршрута
```

**Число этажей любое.** Сколько файлов `maps/map<N>.svg`, столько этажей: `build_graph.py` записывает список в `meta.floors` файла `data/data.json`, а приложение и service worker берут этажи оттуда (вкладки, загрузка карт, офлайн-кеш). Лестницы соединяются по одинаковому номеру (`ladder-1`) на соседних этажах.

Скрипт находит коридоры, строит проходимую область, соединяет двери и углы видимостью, проверяет связность и выводит замечания (комната без двери, дверь не у комнаты и т. д.). Названия вроде `dining room` заменяются русскими через `tools/names.json`; значением может быть список: первое — основное название, остальные сохранятся как `aliases` (для будущего поиска).
