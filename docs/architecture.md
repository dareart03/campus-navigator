# Архитектура и путь одного нажатия (C2, C9)

[← К README](../README.md)

Три слоя; стрелки показывают, кто кого вызывает. Нижние слои ничего не знают о верхних, поэтому логика проверяется тестами без браузера.

```
 ┌──────────────────────── ИНТЕРФЕЙС (DOM, браузер) ────────────────────────┐
 │ index.html · sw.js                                                       │
 │ app.js ── собирает экран, слушает нажатия, рисует маршрут и подсветку    │
 │ gestures.js (жесты)   compass.js (датчик)   ocr.js (фото, веб-воркер)    │
 └───────────────┬──────────────────────────────────────────────────────────┘
                 │ вызывает
 ┌───────────────▼──────────── ЛОГИКА (чистые функции, без DOM) ────────────┐
 │ graph.js + heap.js   проверка графа, Дейкстра         ◄── тесты         │
 │ search.js            поиск, избранное, недавние            node --test  │
 │ names.js · signs.js  надписи и номера с фото                            │
 │ steps.js · nav.js · session.js · share.js · viewmath.js · culling.js    │
 └───────────────┬──────────────────────────────────────────────────────────┘
                 │ читает
 ┌───────────────▼──────────────────── ДАННЫЕ ─────────────────────────────┐
 │ maps/map*.svg  (рисунок)   data/data.json  (граф)   tools/names.json    │
 └───────────────▲──────────────────────────────────────────────────────────┘
                 │ создаёт (один раз, при сборке)
          tools/build_graph.py  ◄── run.py
```

**Путь одного нажатия: от экрана до хранилища.** Палец на аудитории (экран) → `app.js` определяет id комнаты на карте (`room-311` → `f3-room-311`) и вызывает `selectNode`. Первое нажатие запоминает старт. Второе нажатие (логика) → `graph.js` ищет путь Дейкстрой по куче (`heap.js`, данные берёт из графа `data.json`) → `steps.js` делит путь на шаги → снова экран: `app.js` красит линию и обводку и показывает шаги. После этого состояние уходит в хранилище: `session.js` пишет этаж, вид, старт и финиш в `sessionStorage`, `share.js` обновляет адресную строку (`?from=…&to=…`), `search.js` кладёт маршрут в «недавние» в `localStorage` (там же избранное). `session.js` получает объект хранилища снаружи, а `search.js` читает `localStorage` в двух маленьких функциях (`loadJSON`, `saveJSON`) с запасным значением; поэтому тесты подставляют своё хранилище и проверяют, что мусор и недоступное хранилище не роняют приложение.

**Путь до сети.** Сетевых запросов к чужим серверам нет. При старте `app.js` делает `fetch` своих файлов: `data/data.json` и `maps/map<N>.svg` (число этажей берётся из графа). Service worker (`sw.js`) кладёт их в кеш: онлайн всегда свежие, офлайн из кеша. Фото двери (`ocr.js` → воркер tesseract) обрабатывается на устройстве и никуда не отправляется.
