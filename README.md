# Навигатор по корпусу

**Сайт:** <https://dareart03.github.io/campus-navigator/>

Индивидуальный проект (тема 12). Приложение показывает план многоэтажного корпуса и строит кратчайший маршрут между аудиториями, в том числе между этажами, с пошаговыми указаниями. Ищет аудитории и места (туалеты, выходы, столовую), делится маршрутом по ссылке и QR-коду, определяет старт по фото двери, поворачивает карту по компасу и работает без сети. Статический сайт без фреймворков: HTML + ES-модули, карты в SVG, граф в JSON, поиск пути Дейкстрой.

## Как собрать (C1)

Нужны Python 3.9+ и интернет (один раз, для зависимостей). Для тестов желательно Node.js 20+.

```powershell
git clone https://github.com/dareart03/campus-navigator.git
cd campus-navigator
python run.py
```

`run.py` создаёт `.venv`, ставит зависимости, строит граф из `maps/map*.svg` в `data/data.json`, запускает тесты и сервер (<http://localhost:8000>). Параметры: `--skip-build`, `--skip-tests`, `--no-serve`, `--port`. Карта своего кампуса: [docs/own-campus.md](docs/own-campus.md).

## Архитектура (C2, C9)

Три слоя; нижние ничего не знают о верхних, поэтому логика проверяется тестами без браузера. Путь одного нажатия от экрана до хранилища и сети: [docs/architecture.md](docs/architecture.md).

```
 ┌──────────────────────── ИНТЕРФЕЙС (DOM, браузер) ────────────────────────┐
 │ index.html · sw.js                                                       │
 │ app.js ── собирает экран, слушает нажатия, рисует маршрут и подсветку    │
 │ gestures.js (жесты)   compass.js (датчик)   ocr.js (фото, веб-воркер)    │
 └───────────────┬──────────────────────────────────────────────────────────┘
                 │ вызывает
 ┌───────────────▼──────────── ЛОГИКА (чистые функции, без DOM) ────────────┐
 │ graph.js + heap.js   проверка графа, Дейкстра         ◄── тесты         │
 │ search.js            поиск, избранное, недавние            node --test  │
 │ names.js · signs.js  надписи и номера с фото                            │
 │ steps.js · nav.js · session.js · share.js · viewmath.js · culling.js    │
 └───────────────┬──────────────────────────────────────────────────────────┘
                 │ читает
 ┌───────────────▼──────────────────── ДАННЫЕ ─────────────────────────────┐
 │ maps/map*.svg  (рисунок)   data/data.json  (граф)   tools/names.json    │
 └───────────────▲──────────────────────────────────────────────────────────┘
                 │ создаёт (один раз, при сборке)
          tools/build_graph.py  ◄── run.py
```

## Известные ограничения (C2)

- Компас работает только по https (на GitHub Pages да) и на устройствах с датчиком; направление «вверх» плана калибруется один раз.
- Фото двери: нужна чёткая табличка; первое распознавание скачивает около 7 МБ (надписи ещё около 3 МБ); нужен браузер с WebAssembly SIMD (телефоны с 2021 года).
- Лестницы соединяют только соседние этажи с одинаковым номером (`ladder-1`).
- Часть тестов проверяет данные именно этого здания: на других картах они падают (тесты кода не зависят от карт).
